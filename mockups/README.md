# วิธีเปลี่ยนภาพชั้นวาง (view2.png)

หน้าจอแบบที่ 1 วางตารางไฮไลท์ **ทับ** ภาพถ่ายชั้นวาง

ภาพปัจจุบัน `view2.png` มีแผ่นไม้ **7 แผ่น** → ช่องว่างระหว่างแผ่น **6 ชั้น**
ตรงกับ `SHELVES = 6` พอดี ✅ (แผ่นบนสุดคือหลังคา ไม่ใช่ชั้นเก็บของ)

---

## ภาพที่ต้องการ (ถ้าจะเปลี่ยนอีก)

- ชั้นวางมองจาก**ด้านหน้าตรงๆ** ไม่เอียง (ภาพ perspective วัดพิกัดไม่ได้)
- ช่องเก็บของ **6 ชั้น** = แผ่นไม้ 7 แผ่น
- ชั้นว่าง ไม่มีของวาง — ของจะบังกรอบไฮไลท์
- พื้นหลังเรียบ สว่าง
- กว้างประมาณ 1600-1800 px ก่อน crop

## ขั้นตอน

1. วางไฟล์ใหม่ไว้ที่ root ของโปรเจกต์
2. บอกผมได้ เดี๋ยววัดพิกัดให้ — หาขอบซ้าย/ขวาของโครงเหล็ก และ
   กึ่งกลางแผ่นไม้ทุกแผ่นจากพิกเซลจริง
3. crop ตัดผนัง/พื้นทิ้ง แล้วย่อครึ่ง
   (1.4 MB → 327 KB · เครื่อง PDA โหลดผ่าน WiFi เร็วขึ้นมาก)
4. แก้ `RACK_IMG` ใน `shared.js`

```js
const RACK_IMG = {
  src: 'view2.png',
  w: 850, h: 355,       // ขนาดหลัง crop + ย่อ
  x0: 26, x1: 821,      // ขอบซ้าย/ขวาของโครงชั้นวาง
  decks: [13, 65, 112, 161, 210, 257, 307],  // กึ่งกลางแผ่นไม้ บนลงล่าง
};
```

**ใช้พิกัดแผ่นไม้จริง ไม่ได้แบ่งเท่าๆ กัน** เพราะ perspective ของเลนส์ทำให้
ระยะห่างแต่ละชั้นไม่เท่ากัน (52, 47, 49, 49, 47, 50 px) ถ้าแบ่งเท่ากัน
กรอบจะเลื่อนจากแผ่นไม้จริงไปหลายพิกเซล

`shelves` คำนวณเองจาก `decks.length - 1` ไม่ต้องกรอก
ถ้าไม่ตรงกับ `SHELVES` หน้าจอจะขึ้นคำเตือนสีส้มให้อัตโนมัติ

|---|---|
| A | 4 |
| B, C, D, E | 6 |
