# คำศัพท์ — เรียกให้ตรงกัน

ใช้คำพวกนี้เวลาคุยกันเรื่องหน้าจอ PDA จะได้ไม่สับสน
(คำในวงเล็บ = ชื่อตัวแปรในโค้ด)

---

## หน้าจอ PDA มี 3 ส่วน

```
┌─────────────────────────────┐
│  K63                        │ ← 1. รหัสตำแหน่ง
│  โซน K · ชั้นที่ 6 · ช่องที่ 3 │
├─────────────────────────────┤
│ ① เดินไปชั้นวางโซน K        │
│  ┌───────────────────────┐  │
│  │   [ผังคลัง มองจากบน]  │  │ ← 2. ผังคลัง
│  └───────────────────────┘  │
├─────────────────────────────┤
│ ② ชั้นที่ 6 · ช่องที่ 3      │
│  ┌───────────────────────┐  │
│  │  [ชั้นวาง มองด้านหน้า] │  │ ← 3. ภาพชั้นวาง
│  └───────────────────────┘  │
└─────────────────────────────┘
```

| # | เรียกว่า | คืออะไร | ไฟล์ |
|---|---|---|---|
| 1 | **รหัสตำแหน่ง** | ตัวใหญ่เขียวบนสุด เช่น `K63` | `PdaScan.tsx` |
| 2 | **ผังคลัง** | ภาพคลังมองจากด้านบน ไฮไลท์ว่าอยู่โซนไหน | `WarehouseFloorPlan.tsx` |
| 3 | **ภาพชั้นวาง** | ภาพชั้นวางมองจากด้านหน้า ไฮไลท์ชั้น/ช่อง | `ShelfFront.tsx` |

---

## รหัสตำแหน่ง แยกเป็น 3 ส่วน

```
K 6 3
│ │ └── ช่อง  (slot)  นับจากซ้าย 1-7
│ └──── ชั้น   (aisle) นับจากล่าง 1-6
└────── โซน   (zone)  A-K
```

| คำ | ตัวแปร | ค่า | นับยังไง |
|---|---|---|---|
| **โซน** | `zone` | A–K | ตัวอักษรหน้าสุด |
| **ชั้น** | `aisle` | 1–6 | **นับจากล่างขึ้นบน** ชั้น 1 = ล่างสุด |
| **ช่อง** | `slot` | 1–7 | **นับจากซ้ายไปขวา** ช่อง 1 = ซ้ายสุด |

> ⚠️ `aisle` เป็นชื่อเดิมตั้งแต่ตอนที่ยังไม่มีช่อง ความหมายจริงคือ **ชั้น**
> ไม่ได้แปลว่า "ทางเดิน" เปลี่ยนชื่อไม่ได้เพราะผูกกับคอลัมน์ใน DB

## ส่วนประกอบในภาพชั้นวาง

```
        ┌─────┐
        │▓▓▓▓▓│ ← แถบช่อง 7 (TOP_STRIP)
════════╪═════╪════════  ← หลังคา (แผ่นไม้บนสุด ไม่ใช่ชั้นเก็บของ)
 │   │  │  │  │   │   │
 │   │  │▓▓│  │   │   │ ← กรอบไฮไลท์ (ช่องที่สินค้าอยู่)
─┼───┼──┼──┼──┼───┼───┤  ← แผ่นไม้ (deck)
 │   │  │  │  │   │   │  ← ชั้น (ช่องว่างระหว่างแผ่นไม้)
─┼───┼──┼──┼──┼───┼───┤
 │   │  │  │  │   │   │
 ↑   ↑
 เสา (post) — ขอบแบ่งช่อง
 1   2  3  4  5   6      ← ช่อง (bay) มี 6 ช่องในภาพ
```

| คำ | ตัวแปร | หมายถึง |
|---|---|---|
| **เสา** | `BAY_EDGES` | เสาเหล็กแนวตั้ง 7 ต้น → แบ่งเป็น 6 ช่อง |
| **ช่อง** | `BAY_EDGES[i]` | พื้นที่ระหว่างเสา 2 ต้น |
| **แผ่นไม้** | — | แผ่นรองของ มี 7 แผ่น |
| **ชั้น** | `GAPS` | ช่องว่าง**ระหว่าง**แผ่นไม้ = ที่วางของจริง มี 6 ชั้น |
| **หลังคา** | — | แผ่นไม้บนสุด ไม่ใช่ชั้นเก็บของ |
| **แถบช่อง 7** | `TOP_STRIP` | แถบเขียวเหนือหลังคา = ช่องที่ 7 |
| **กรอบไฮไลท์** | `.sf-hit` | กรอบเขียวบอกว่าของอยู่ตรงไหน |

### ทำไมช่องท้ายๆ ต้องอยู่ด้านบน

ภาพชั้นวางมีช่องตามเสาจริงเท่านั้น แต่บางโซนใช้ช่องมากกว่านั้น
ถ้าอัดให้ครบทุกช่อง กรอบจะไม่ทับเสาเลยสักช่อง

จึงแยกช่องที่เกินออกมาเป็น**แถบเหนือชั้นวาง** → ช่องที่เหลือตรงกับเสาจริงพอดี

## ชั้นวางมี 2 แบบ

คลังมีชั้นวาง 2 ขนาด จึงใช้ภาพ 2 ภาพ

| ภาพ | ใช้กับ | ชั้น | ช่อง | แถบบน |
|---|---|---|---|---|
| `rack-front.png` | โซน B–K และ **โซน A ชั้น 3–4** | 6 | 6 | ช่อง 7 (กว้างเท่าช่อง 5) |
| `rack-zone-a.png` | **โซน A ชั้น 1–2** เท่านั้น | 2 | 2 | ช่อง 3 (ซ้าย) · ช่อง 4 (ขวา) |

### ⚠️ โซน B, D, F, H, J นับเชลฟ์จากขวาไปซ้าย

ชั้นวางกลุ่มนี้อยู่อีกฝั่งของทางเดิน พนักงานเดินเข้าหาจากคนละด้าน
**เชลฟ์ที่ 1 จึงอยู่ขวาสุด** ของภาพ ไล่ไปซ้าย

| โซน | เชลฟ์ 1 | เชลฟ์ 6 |
|---|---|---|
| A, C, E, G, I, K | ซ้ายสุด | ขวาสุด |
| **B, D, F, H, J** | **ขวาสุด** | **ซ้ายสุด** |

กลับเฉพาะ**แนวนอน** — ชั้นยังนับล่างขึ้นบนเหมือนกันทุกโซน
แถบชั้นที่ 7 ก็ย้ายไปฝั่งตรงข้ามด้วย

ในโค้ดคุมด้วย `MIRRORED_ZONES` ใน `ShelfFront.tsx`

### โซน A ใช้ชั้นวาง 2 ชุดคนละขนาด

```
เชลฟ์ 3-4 (A3X, A4X)  ชั้นสูง  → rack-front.png
เชลฟ์ 1-2 (A1X, A2X)  ชั้นเตี้ย → rack-zone-a.png
```

ชั้นเตี้ยเป็นชั้นวาง 2 ตัวตั้งติดกัน **อ่านแกนเหมือนโซนอื่นทุกประการ**

```
   ┌─ A14 ─┐ ┌─ A24 ─┐   ← ชั้นที่ 4 = แถบเหนือชั้นวาง
   │  A13  │ │  A23  │
   │  A12  │ │  A22  │
   │  A11  │ │  A21  │   ← ชั้นที่ 1 = ล่างสุด
    เชลฟ์ 1    เชลฟ์ 2
```

ในโค้ดเลือกภาพด้วย `pickRack()` — ยืนยันจากรูปที่หน้างานทำเครื่องหมายมา

รหัสที่มีจริง:

| เชลฟ์ | รหัส |
|---|---|
| 1 | A11 A12 A13 A14 |
| 2 | A21 A22 A23 A24 |
| 3 | A31 A32 A33 A34 A35 A36 |
| 4 | A41 A42 A43 A44 A45 A46 |

## คำที่มักเรียกสลับกัน

| ❌ อย่าเรียก | ✅ เรียกว่า |
|---|---|
| ชั้นวาง (หมายถึงช่องเดียว) | **ช่อง** |
| ล็อก / ช่องเก็บ | **ช่อง** |
| แถว | **ชั้น** (แนวนอน) หรือ **ช่อง** (แนวตั้ง) |
| ทางเดิน | **ชั้น** (`aisle` เป็นชื่อตัวแปรเท่านั้น) |
| บล็อกเขียว / กล่องเขียว | **กรอบไฮไลท์** |

---

## รหัสที่อ่านไม่ออก

รหัสที่ไม่เข้ารูปแบบ `<โซน><ชั้น><ช่อง>` จะแสดง**รหัสตัวใหญ่**แทนภาพ

| รหัส | ทำไม |
|---|---|
| `PRE`, `COOL`, `DELETE` | ไม่มีตัวเลข |
| `L1`, `L2` | เลขหลักเดียว แยกชั้น/ช่องไม่ได้ |
| `กล่อง`, `โหล`, `แผง` | เป็นหน่วยนับ ไม่ใช่ตำแหน่ง |

เรียกว่า **fallback** — เป็นพฤติกรรมที่ตั้งใจ ไม่ใช่ error
